Ilhan Louhichi — Portfolio (v2)
===============================

Contenu:
- index.html, about.html, experience.html, projects.html, contact.html
- css/styles.css
- js/particles.js (canvas-based particles background)
- files/.gitlab-ci.yml (exemple avancé)
- files/k8s-deployment.yaml (manifest exemple)
- LOUHICHI_ILHAN_CV (2).pdf (copie de ton CV)

Comment personnaliser:
- Ouvre les fichiers HTML et modifie le texte directement.
- Places tes captures d'écran dans 'assets' et référence-les dans les pages.
- Pour intégrer un vrai formulaire, remplace l'attribut 'action' du <form> par un endpoint (ou Netlify Forms).

Déploiement rapide:
Option A — GitHub Pages:
1. Crée un repo public.
2. Pousse le contenu de ce dossier à la racine du repo.
3. Active Pages dans Settings → Pages.

Option B — Netlify:
1. Dézippe et drag & drop le dossier sur https://app.netlify.com/drop

Observations:
- Le fond animé est un canvas JS léger et n'utilise pas de dépendances externes.
- Les polices Orbitron & Inter sont chargées via Google Fonts (nécessite internet).
