Veille Technologique : Le Cloud Computing

Dans le cadre de ma formation BTS SIO ainsi que de mon alternance chez Thales, j’ai choisi de réaliser une veille technologique sur le Cloud Computing. Cette technologie est aujourd’hui incontournable dans les entreprises modernes, car elle permet d’héberger des services, stocker des données, sécuriser les infrastructures et automatiser les déploiements.

📌 Qu'est-ce que le Cloud Computing ?

Le Cloud Computing consiste à utiliser des serveurs distants accessibles via Internet afin de fournir des ressources informatiques à la demande :

  • Serveurs virtuels
  • Stockage de données
  • Base de données
  • Applications web
  • Sécurité réseau
  • Outils DevOps

Les principaux fournisseurs Cloud sont : AWS, Microsoft Azure et Google Cloud Platform.

📈 Pourquoi ce sujet ?

Le Cloud est directement lié aux métiers de :

  • Administrateur systèmes et réseaux
  • Ingénieur DevOps
  • Cybersécurité
  • Développeur Full Stack
  • Architecte Infrastructure

Étant actuellement en alternance dans le domaine DevOps, cette veille me permet de suivre les évolutions utilisées en entreprise.

🚀 Tendances Cloud en 2025

  • Multi-Cloud : utilisation de plusieurs fournisseurs cloud
  • Serverless : exécution de code sans gérer les serveurs
  • Kubernetes : orchestration de conteneurs
  • Infrastructure as Code : Terraform / Ansible
  • Cloud sécurisé : Zero Trust & IAM
  • IA dans le Cloud : services IA hébergés
