Veille Technologique — Cloud Computing

Dans le cadre de ma formation BTS SIO et de mon alternance chez Thales, j'ai choisi de réaliser une veille technologique sur le Cloud Computing. Cette technologie est aujourd'hui incontournable dans les entreprises modernes, permettant d'héberger des services, stocker des données, sécuriser les infrastructures et automatiser les déploiements.

📌 Qu'est-ce que le Cloud Computing ?

Le Cloud Computing consiste à utiliser des serveurs distants accessibles via Internet afin de fournir des ressources informatiques à la demande. Il se décline en plusieurs modèles :

🖥️

IaaS

Infrastructure as a Service — serveurs virtuels, stockage, réseau à la demande.

⚙️

PaaS

Platform as a Service — environnements de développement et déploiement managés.

☁️

SaaS

Software as a Service — applications accessibles directement via le navigateur.

Principaux fournisseurs

AWS Microsoft Azure Google Cloud Platform OVHcloud

🚀 Tendances Cloud 2025

🔀

Multi-Cloud

Utilisation simultanée de plusieurs fournisseurs cloud pour éviter les dépendances et optimiser les coûts.

⚡

Serverless

Exécution de code sans gérer les serveurs — AWS Lambda, Azure Functions, Google Cloud Run.

🐳

Kubernetes

Orchestration de conteneurs Docker pour des déploiements scalables et résilients.

📝

Infrastructure as Code

Gestion de l'infrastructure via du code — Terraform, Ansible, Pulumi.

🔐

Cloud Sécurisé

Zero Trust, IAM, chiffrement bout en bout — la sécurité native au cloud.

🤖

IA dans le Cloud

Services IA hébergés — SageMaker, Azure AI, Vertex AI pour le machine learning.
